換電腦：
1. 解壓縮此完整專案，在新的電腦開啟 rsao-main 資料夾。

3. 依 .env.example 從原環境安全移轉所需環境變數，不要把金鑰放入公開版本庫。
4. 本機執行 npm run dev；部署前執行 npm run build。
5. 使用實際外部諮詢單驗證讀取、回覆預覽、寫入位置。
