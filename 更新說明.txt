後台手機介面與回傳穩定性整合更新 2026-11-19

尚未部署。此包含 16 個程式／測試檔及說明，基礎為先前整合更新、11/17 v3 回傳修正、11/18 付款相容修復。只合併同路徑檔案，勿刪除其他檔案；如 GitHub 有其他人的更新，請比對差異合併，避免覆蓋。

手機後台
・文字與視訊訂單各每頁只顯示 5 筆，按下一頁才顯示下一批；修改篩選會回第一頁，縮放後頁碼會重設。桌機原有筆數選項保留。
・目前是後台資料載入後的畫面分頁，並非按下一頁才向資料庫抓資料；這次處理手機畫面密度，沒有改動整個資料載入方式或營收統計範圍。
・縮小次要按鈕、諮詢單圖示與分頁操作，手機隱藏紅色「✦ 回覆」入口（使用固定句庫建立回覆的按鈕），電腦版保留。不刪除既有潤稿或回傳功能。
・修正網站共用 header 76px、nav 56px 固定高度滲入後台區塊的問題。待處理區、營收、分頁改為隨內容增高；頂部操作換行、訂單卡片與文件操作按鈕重新排列。

營收與通知名單
・每月營收改為預設收合的小區塊，可看到月份和合計金額，展開後才顯示月選單、扣視訊費勾選與明細。原本排除 Nnn/Peggy 的規則保留。
・移除 LINE 即時通知名單入口、關閉名單管理 API（登入後回410），並移除 webhook 的名單轉發通知。仍保留來訊聯絡人名稱同步，不影響其他付款／預約通知。沒有刪除資料庫歷史名單，也沒有執行資料庫清除。

付款
・介面與儲存 API 只接受銀行轉帳、藍新金流；移除自動切換付款的失敗寫入流程。
・資料庫若仍留舊 auto 值，新程式將其當作銀行轉帳，不再自動判斷；需要藍新時可在後台明確選擇藍新金流。原本明確選擇藍新的設定保留。
・保留前次緊急修復：新帳號管理表缺少時不拖垮整份預約列表；僅對原來兩個已知收款帳號提供缺表相容，不會把自訂帳號擅自換成別的帳號；轉帳頁保留缺快照欄位的舊版相容。
・本次無新增資料表、不需要新 SQL 或環境變數。若要使用先前新增／編輯銀行帳號功能，既有 058 資料庫更新仍須完成。

回傳檢查
・正式姓名與項目標題辨識集中到共用函式，前端與伺服器使用同一規則。
・有正式具名主標題時，正文裡只有【建議文字】的段落不再被當成另一個姓名／項目標題。保留姓名／項目不同、文件已變更、重複內容等攔截。
・空白 Q/A 後面接姓名項目標題時，文字正規化不會再把標題併進上一個問題／回答。
・在最後確認前預先核對，標題不同時指出文件標題及所選版本標題，切到需要核對的項目並保留草稿；可切回原始版本或修正正式標題，不會自動覆寫原稿、重送訊息或放寬姓名核對。
・已唯讀讀取使用者提供的問題文件，文件有 4 項；以該文件原始回傳內容做比對，修改前原本就能通過。因此尚未取得當時所選潤稿／草稿的實際差異，不能認定此次單筆錯誤已完全重現或保證所有回傳錯誤都已解決。新診斷會直接顯示差異，方便確認。
・本包亦包含 v3 紅字／藍字清單相容處理。
